
# Community Water Quality Analysis

A Python-based project exploring water quality data through data cleaning, exploratory data analysis, visualisation, and experimental machine learning.

## Project Overview

This project explores water quality parameters to understand patterns and relationships in the dataset.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Status

Currently being organised and improved as a learning and portfolio project.

## Disclaimer

This is an educational data analysis project. Model outputs are exploratory and should not be used to determine whether water is safe to drink.
